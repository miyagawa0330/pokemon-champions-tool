# 更新版の動作検証

アプリを開くだけなら開発用ソフトは必要ありません。クラウドの作業場所には、以下の検証に使うソフトがあります。

## 自動検証

このフォルダで実行します。Node.js 22以上、追加パッケージ不要です。

```sh
node --test tests/core.test.js tests/update.test.js
```

20件の検証で、全ポケモン・全技・別名検索、追加データと2資料の一致、タイプ相性、固定条件のダメージ、4種の参照能力処理、未対応技の計算拒否、特性を自動適用しないこと、現レギュレーションを根拠なく確定しないこと、原本の保管を確認します。

計算可能な280技×3組（840通り）は、同じデータを渡した元v7の基本計算と比較しています。この比較は対応範囲の計算を保ったことの確認で、ゲームの全仕様を再現している証明ではありません。対象外に変更した技は別の検証で「結果を出さず理由を表示する」ことを確認します。

`.github/workflows/test.yml` に、GitHubへの保存後に同じ20件を実行する設定もあります。クラウド内とGitHub側の結果は別です。GitHub側はリポジトリの「Actions」で確認できます。

## ブラウザー操作

```sh
python3 tests/browser_smoke.py
```

PythonのPlaywrightとChromiumを使用します。一時HTTPサーバーを自動起動して、終了時に止めます。パソコン幅1280pxとスマートフォン幅390pxで、5機能、追加データの検索、未確認表示、計算の注意書き、対象外の理由、JavaScriptエラーや必要ファイルの読み込み失敗を確認します。

起動済みのサーバーも確認する場合は `--url http://127.0.0.1:8000` を追加します。ローカルファイルを直接開ける開発環境では `--file` を追加できますが、このクラウドでは管理ポリシーで禁止されるため未検証です。MacのSafari本体も未検証です。

## 以前の分割時専用の検証

`tests/v7-parity.test.js` は、v7からデータを変えずに分割した時点専用です。今回、データと注意書きを意図的に更新しているため、通常の検証には使いません。原本を上書きして比較を通すことはしません。原本保管の検証は今回の `update.test.js` に含まれます。

## Macで確認する例

- `げんがー` の検索と、ゲンガー/メガゲンガーの種族値比較（500/600）。
- `メガセグレイブ` の検索で「二次資料を照合して追加した参考データ」「利用可否：未確認」が出る。
- 「ほのお」で攻撃相性を表示すると、くさ2倍、みず1/2倍。
- ピカチュウ→ギャラドス、10まんボルトは70.3%〜83.2%の簡易計算。
- でんじは→ガブリアスは変化技で計算対象外。ロックブラストは連続攻撃未対応で対象外。
- 技検索でスターアサルトを表示すると、威力が未確認で計算対象外と出る。

入力候補がボタンに重なった場合は、候補を選ぶか見出しをクリックして閉じてから操作してください。
