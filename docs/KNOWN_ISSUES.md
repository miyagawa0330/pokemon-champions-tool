## ダメージ計算の仕組み

`js/calculations.js` に元の処理を移しています。現在は固定条件による目安です。

- Lv.50、個体値31相当、参照能力の能力ポイント32相当。HPは `floor((2×種族値 + 個体値 + 2×ポイント) × Lv / 100) + Lv + 10`、その他は同じ前半に `+5` を加えます。
- 物理技は攻撃側のこうげきと防御側のぼうぎょ、特殊技はとくこうととくぼうを使います。
- 基礎ダメージにタイプ一致（通常1.5倍）とタイプ相性、85〜100の16通りの乱数を掛けます。結果を防御側HPに対する割合として表示し、HP以上になる乱数の数から確率を出します。
- アクロバットは道具なしで威力2倍、ボディプレスは攻撃側のぼうぎょ、イカサマは相手のこうげき、サイコショックは相手のぼうぎょを参照します。
- 性格、持ち物、天候、能力ランク、急所、やけど、特性による無効・軽減・威力変化、連続技や変動威力の詳細などは原則反映しません。

## 具体的に確認した問題

1. **特性を選べません。** 特性一覧に「てきおうりょく」があると、常にタイプ一致を2倍にします。ドラミドロやイダイトウでは、別の特性を使っている場合にも適用されます。
2. **変化技を無効タイプに使うと0%の計算結果が出ます。** 例：ピカチュウ→ガブリアスの「でんじは」。本来この画面では変化技を計算対象外と表示しますが、タイプ無効の判定が先に行われるため0%になります。
3. **`settings.nature` は使われません。** データに値がありますが、変えても性格補正は反映しません。
4. **入力候補が操作ボタンに重なる場合があります。** 候補を選ぶか、画面の見出しをクリックして閉じると操作できます。元のv7と同じ配置です。
