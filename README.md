# ポケモンチャンピオンズ検索ツール — v7 開発の土台

添付された v7 の見た目・5機能・データ・計算方法を保ったまま、更新する場所を分けました。ポケモン313体、技466種、18タイプ。元データの確認日は2026年7月7日、レギュレーションはM-Bです。最新データへの更新はしていません。

## Macで開く（追加ソフト不要）

1. GitHubの `v7-foundation` ブランチで「Code」→「Download ZIP」を選び、Macの「ダウンロード」フォルダでZIPをダブルクリックします。
2. 展開されたフォルダ（GitHubから取得した場合は `pokemon-champions-tool-v7-foundation`）を開きます。
3. その中の `index.html` を右クリックして「このアプリケーションで開く」→「Safari」または「Google Chrome」を選びます。
4. 上の5つのボタンから機能を選べます。

`index.html` だけを別の場所に移さず、フォルダ一式を一緒に置いてください。インターネットやアカウント、サーバーの起動は不要です。

原本を試す場合は、`originals` フォルダの `pokemon_champions_webapp_v7_regulation_mb.html` を同じ方法で開いてください。この原本は単独でも開けます。

## 更新する場所

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の項目と5つのタブ |
| `css/style.css` | 色・文字サイズ・配置 |
| `data/pokemon.js` | ポケモンの名前、タイプ、特性、種族値 |
| `data/moves.js` | 技の名前、分類、威力、効果、別名 |
| `data/types.js` | 18タイプと相性表 |
| `data/settings.js` | 計算条件とデータの確認日・出典 |
| `js/search.js` | 名前の検索と表記の揺れへの対応 |
| `js/calculations.js` | タイプ相性とダメージ計算 |
| `js/app.js` | 結果表示・タブ切り替え・入力候補 |
| `tests/` | 更新後に動作を確認するための検証 |
| `originals/` | 元のv7と、作業前のリポジトリのHTML |
| `CHANGELOG.md` | 更新履歴 |
| `docs/KNOWN_ISSUES.md` | 元のv7の制限と未登録情報 |

データを変えると画面上の登録件数も変わります。確認日と計算条件の表示も `data/settings.js` を参照します。データは読みやすく改行した形式です。JavaScript形式にしているのは、MacでHTMLを直接開いてもデータを読み込めるようにするためです。外部ライブラリや作成専用のソフトは使っていません。

今後は「○○のデータを更新して」「○○の機能を追加して」と依頼してください。必要なファイルの編集と検証はこちらで行えます。自分で編集する場合の注意点は [更新ガイド](docs/UPDATING.md) にあります。

## 変更前に戻す

すぐに元のv7を使うには、`originals/pokemon_champions_webapp_v7_regulation_mb.html` を開いてください。原本の内容は一切変更していません。

Git（変更を保存する仕組み）でも、原本の保管と構成整理を別々に保存しました。保存地点には `pokemon-v7-original` と `pokemon-v7-foundation` という名前を付けています。元のリポジトリのHTMLもGitの履歴と `originals/repository-index-before-v7.html` に残しています。

Gitの履歴はクラウドとGitHubに保存します。GitHubでは元の `main` と分けて、`v7-foundation` ブランチに保存します。GitHubから取得するZIPには原本・更新履歴・説明書が入っています。Gitの履歴そのものはZIPに含まれず、GitHubで確認できます。Macで試すだけならGitの設定もインストールも不要です。前の版に戻したいときは、そのまま依頼してください。

## 動作の確認

詳しい実行方法と確認結果は [検証の説明](docs/TESTING.md) にあります。普段の自動検証は次の1行です（開発用。アプリの利用には不要）。

```sh
node --test tests/core.test.js
```

ブラウザーでの確認は、たとえば次の操作で行えます。

- ポケモン名で `げんがー` を検索する → ゲンガーとメガゲンガーが表示される。
- 種族値比較でゲンガーとメガゲンガーを選ぶ → 合計500と600。
- タイプ相性で「使用する技」「ほのお」を選ぶ → くさは2倍、みずは1/2倍。
- ダメージ計算でピカチュウ→ギャラドス、10まんボルト → 70.3%〜83.2%。
- 技検索で `しゃどーぼーる` を入力し候補を選ぶ → 分類・威力・効果が表示される。

入力欄の下に候補が出たら、候補を選ぶか、見出しをクリックして閉じてからボタンを押してください。

## GitHubから受け取る

[整備済みのv7を開く](https://github.com/miyagawa0330/pokemon-champions-tool/tree/v7-foundation) → ファイル一覧の上にある「Code」→「Download ZIP」。受け取りにはこの手順を使ってください。初回に作成したZIPはクラウド内部の保存場所にあり、チャットのリンクではMacへ渡せませんでした。GitHubでアプリのファイルを保存することと、アプリを公開サイトとして配信することは別です。
