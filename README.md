## Macで開く

1. [更新版のページ](https://github.com/miyagawa0330/pokemon-champions-tool/tree/current-environment-2026-10-12) を開きます。
2. ファイル一覧の上の「Code」→「Download ZIP」を選びます。
3. Finderの「ダウンロード」で取得したZIPをダブルクリックします。
4. 展開されたフォルダの `index.html` を右クリック→「このアプリケーションで開く」→「Safari」または「Google Chrome」を選びます。

追加ソフトは不要です。`index.html` だけを別の場所に移さず、フォルダ一式を一緒に置いてください。ネットへの接続なしでも使えます。

画面上部と検索結果に確認状況を表示しています。「未確認」は、使えないという意味でも、使えるという意味でもありません。過去のv7由来のデータと、二次資料から追加した参考データを区別しています。

## ダメージ計算について

結果は固定条件での**簡易計算の目安**です。特性・道具・天候などを反映した実戦の正確なダメージや勝敗確率とは表示していません。画面の「計算する条件・計算しない条件」で対応範囲を確認できます。

変化技、威力が未確認の技、資料で確認した未対応の変動威力・連続攻撃・固定ダメージ・一撃必殺技などは計算対象外にし、理由を表示します。特性「てきおうりょく」も、自動では適用しません。
